# SQL_PR2_Data_Transfomer
Data_t – SQL Database Project
📌 Project Overview
Data_t is a SQL database project designed to practice basic and intermediate SQL concepts. This project focuses on managing customer details, order information, and employee records using relational database concepts.
🗄️ Database Tables
1. Customers Table
Stores customer information:
- Customer ID
- First Name
- Last Name
- Email
- Registration Date
2. Orders Table
Stores customer order information:
- Order ID
- Customer ID
- Order Date
- Total Amount
3. Employees Table
Stores employee information:
- Employee ID
- First Name
- Last Name
- Department
- Hire Date
- Salary
📚 SQL Concepts Covered
1. Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN (using UNION in MySQL)
2. Subqueries
- Find customers whose order amount is greater than the average order amount.
- Find employees with salaries above the average salary.
3. Date Functions
- YEAR()
- MONTH()
- DATEDIFF()
- DATE_FORMAT()
4. String Functions
- TRIM()
- CONCAT()
- REPLACE()
- UPPER()
- LOWER()
5. Window Functions
- Running Total using SUM()
- Ranking orders using RANK()
6. CASE Statements
- Assign discounts based on order amounts.
- Categorize employee salaries as High, Medium, or Low.
🎯 Learning Outcomes
- Understand relational databases.
- Create and manage database tables.
- Use Primary Keys and Foreign Keys.
- Retrieve data using different JOIN operations.
- Perform calculations using aggregate functions.
- Work with date and string functions.
- Apply subqueries and window functions.
- Perform conditional data analysis using CASE statements.
🛠️ Tools Used
- MySQL
- SQL
